# Tisot VeOd

גרסה 0.3

בוט שסורק דילי טיסות וחבילות (טיסה+מלון) אמיתיים מישראל ושולח התראה
בטלגרם כשמחיר מתאים לתקציב שהגדרת. רץ אוטומטית כל 3 שעות ב-GitHub
Actions - אין צורך להשאיר מחשב פתוח.

## מה חדש בגרסה הזו (0.3)

1. **עריכת דרישות בקובץ אחד** - `config.json` (שהיה קיים אבל לא באמת
   בשימוש בקוד!) עכשיו הוא מקור האמת האמיתי. עורכים אותו ישירות ב-GitHub
   (Code → config.json → עיפרון לעריכה), בלי לגעת בקוד פייתון.
   יש גם **ממשק עריכה גרפי** למעלה בשיחה הזו - קובעים ערכים בטופס, מקבלים
   את ה-JSON המוכן, ומדביקים ל-`config.json`.
2. **זיהוי חבילות (טיסה+מלון)** - בעבר, כל טקסט שהזכיר מילה כמו "מלון"
   נפסל אוטומטית כ"לא טיסה" (כדי לא לבלבל עם דילי מלונות טהורים). עכשיו
   `package_detector.py` מזהה כשטיסה **וגם** מלון מוזכרים יחד באותו פוסט
   ומתייג את זה כ"חבילה" בנפרד, עם ניקוד לפי תקציב ה-₪ שהגדרת
   (`config.json -> packages`) במקום תקציב הדולר לנוסע בודד.
3. **תיקון חילוץ מחיר בשקלים** - פוסטים ישראליים כותבים לרוב "1,890 ש״ח"
   ולא בסימן ₪, וזה לא זוהה קודם. תוקן.

## מגבלה שנשארה (חשוב להבין)

**אין לנו כרגע מקור אמיתי שמייצר פוסטים של "חבילה" (טיסה+מלון) על בסיס
קבוע** - הערוץ @secretflights בעיקר מפרסם טיסות בלבד. הקוד עכשיו כן
**מזהה נכון** חבילה אם וכשהיא מופיעה (ולא זורק אותה כמו קודם), אבל אי אפשר
להבטיח שחבילות אכן יופיעו בתדירות גבוהה. כמו כן, **אין אימות אוטומטי
לדירוג מלון/כוכבים/מיקום** - זה מודפס בהודעה כתזכורת לבדוק ידנית.

חיפוש חבילות אמיתי ואמין (עם דירוג מלון, 5 נוסעים, מרכז עיר) עדיין דורש
API בתשלום (כמו Amadeus, או שיתוף פעולה עם קשרי תעופה/אשת טורס) - זה
שינוי משמעותי, תגיד לי אם תרצה שאבנה את זה.

## מקורות נוספים - מה שמצאתי ומה שלא הצלחתי לאמת

חיפשתי ערוצי טלגרם ישראליים נוספים מלבד `secretflights`. מצאתי כמה
שמות שנראים רלוונטיים ופעילים (למשל "Teleflight Israel", "Weekend Plus
– נופש בקליק", "הדילים שלי – טיסות") אבל **לא הצלחתי לאמת את שם
המשתמש (@handle) המדויק שלהם** מרחוק בלי גישה חיה לטלגרם.

איך להוסיף אותם בעצמך (2 דקות):
1. פתח את אפליקציית טלגרם, חפש את שם הערוץ (לדוגמה "Weekend Plus נופש בקליק")
2. היכנס לערוץ - שם המשתמש מופיע למעלה (משהו כמו `@nofeshbeklik`) או
   ב"שתף" → "העתק קישור" (`t.me/<handle>`)
3. הוסף את ה-handle (בלי @, בלי t.me/) לרשימת `telegram_channels`
   בטופס העריכה למעלה, מופרד בפסיק מהערוץ הקיים
4. הדבק את ה-JSON המעודכן ל-`config.json` ב-GitHub

זה בטוח לנסות - אם השם שגוי, הבוט פשוט לא ימצא שם כלום (ידפיס שגיאה
בלוג של Actions) ולא יקרוס.

## שלב 1: יצירת בוט טלגרם

1. פתח שיחה עם [@BotFather](https://t.me/BotFather) בטלגרם
2. שלח `/newbot` ועקוב אחרי ההוראות
3. שמור את ה**טוקן** שתקבל
4. פתח שיחה עם הבוט החדש שלך ושלח לו הודעה (למשל "היי")

## שלב 2: מציאת ה-Chat ID שלך

1. פתח שיחה עם [@userinfobot](https://t.me/userinfobot) בטלגרם
2. שמור את ה-ID שהוא שולח לך

## שלב 3: העלאה ל-GitHub והגדרת Secrets

1. צור ריפוזיטורי (אפשר פרטי) והעלה אליו את **כל תוכן** התיקייה (לא את
   התיקייה עצמה - ראו הערה למטה על `.github`)
2. Settings → Secrets and variables → Actions → New repository secret:

| שם | ערך |
|---|---|
| `TELEGRAM_TOKEN` | הטוקן משלב 1 |
| `TELEGRAM_CHAT_ID` | ה-ID משלב 2 |

**חשוב:** `.github` היא תיקייה מוסתרת. אם גרירת קבצים מהמחשב לא מעלה
אותה, צור אותה ידנית: **Add file → Create new file**, בשם הקובץ הקלד
`.github/workflows/search.yml` (עם ה-`/` - GitHub יוצר את התיקיות
לבד), הדבק את התוכן מהקובץ `search.yml` שבתיקייה.

## שלב 4: הפעלה

- הבוט רץ אוטומטית כל 3 שעות (המרווח כבר קיים ולא צריך לשנות אותו -
  אם כן תרצה לשנות, זה ב-`.github/workflows/search.yml`, שורת ה-`cron`)
- להרצה ידנית מיידית: טאב **Actions** → **TisotVeOd** בצד שמאל →
  **Run workflow**

## עריכת הדרישות

**הכי נוח:** השתמש בטופס העריכה האינטראקטיבי (למעלה בשיחה הזו) - קובעים
ערכים, מעתיקים את ה-JSON, ומדביקים ב-`config.json` בגיטהאב.

**ידנית:** ערוך את `config.json` ישירות:

```json
{
  "flights": {
    "max_price_usd": 300,
    "telegram_channels": ["secretflights"],
    "max_results": 10
  },
  "packages": {
    "max_total_price_ils": 4000,
    "max_exception_price_ils": 4200
  }
}
```

- `flights.max_price_usd` - סף מחיר לנוסע בודד לדילי טיסה (דולר)
- `flights.telegram_channels` - ערוצי טלגרם לסריקה
- `flights.max_results` - כמה התראות לכל היותר בהרצה אחת
- `packages.max_total_price_ils` - תקציב מועדף לחבילה (₪)
- `packages.max_exception_price_ils` - תקציב חריגה מותרת לחבילה (₪)
