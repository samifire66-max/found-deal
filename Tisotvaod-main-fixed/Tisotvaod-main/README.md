# Tisot VeOd

גרסה 0.2 - תוקן ועובד

בוט שסורק דילי טיסות אמיתיים מישראל (כרגע מהערוץ הישראלי [@secretflights](https://t.me/secretflights)
בטלגרם) ושולח אליך התראה בטלגרם כשמחיר הטיסה לנוסע נמוך מהסף שהגדרת.
רץ אוטומטית כל 3 שעות דרך GitHub Actions - **אין צורך להשאיר מחשב פתוח**.

## מה תוקן בגרסה הזו

הפרויקט המקורי לא באמת מצא דילים בפועל. הבעיות שתוקנו:

1. **מקורות לא רלוונטיים** - `sources.py` הכיל רק בלוגים אמריקאים/אירופאים
   (The Flight Deal, Secret Flying וכו') שמסקרים בעיקר טיסות *אל* יעדים
   מחו"ל, לא טיסות *מ*ישראל. **נוסף מקור חדש** (`telegram_channel_provider.py`)
   שסורק את הערוץ הישראלי `@secretflights` שמפרסם דילי טיסות אמיתיים
   מנתב"ג על בסיס יומי.
2. **סינון שהיה מסנן הכל** - `flight_detector.py` ו-`extractor.py` זיהו
   רק מילות מפתח באנגלית ("flight", "hotel" וכו'), כך שתוכן בעברית
   (כמו הפוסטים בערוץ הטלגרם) היה נחסם אוטומטית. נוספו מילות מפתח
   ושמות ערים בעברית.
3. **דרישת "TLV" בכותרת** - `relevance.py` דרש שהמילה "tlv"/"tel aviv"
   תופיע במפורש בטקסט (באנגלית) כדי שדיל ייחשב רלוונטי. עכשיו דילים
   שמגיעים מהערוץ הישראלי נחשבים רלוונטים-מבחינת-מוצא אוטומטית (כי
   הערוץ עצמו כבר מסונן לטיסות מישראל), והניקוד מתמקד בעיקר במחיר מול
   הסף שהגדרת (`settings.py -> max_price_usd`).
4. **לא היה תזמון אוטומטי בכלל** - ה-workflow הכיל רק `workflow_dispatch`
   (הרצה ידנית), בלי `schedule`. נוסף cron שמריץ כל 3 שעות.
5. **קוד מת/שבור** - הוסרו `flight_search.py` (ייבוא שבור ל-`MAX_PRICE`
   שלא קיים), `filters.py`, `email_provider.py`, ו-`search_engine.py` -
   כולם לא היו בשימוש בפועל בשום מקום בזרימת הריצה.
6. **שליחה חוזרת של אותם דילים** - נוסף `dedup_store.py` ששומר אילו
   דילים כבר נשלחו (בקובץ `sent_deals.json`, נשמר בין הרצות ב-GitHub
   Actions cache), כדי שלא תקבל שוב ושוב התראה על אותו דיל.
7. **הודעת "לא נמצאו עסקאות" בכל הרצה ריקה** - הוסרה (הייתה שולחת ספאם
   כל 3 שעות כשאין דילים).

## מגבלה חשובה שכדאי לדעת עליה

ה-README המקורי ביקש **חבילות נופש מלאות** (טיסה + מלון, 5 נוסעים,
מלון 3 כוכבים+, ציון 8.5+, מרכז העיר, תקציב כולל עד 4,000-4,200 ₪).

זה **לא ריאלי לבנות אוטומטית כרגע** בלי תקציב לשירות מסחרי, כי:
- אתרי חבילות ישראליים (אשת טורס, קשרי תעופה, טרווליסט וכו') לא
  חושפים API ציבורי - הם דורשים מילוי טופס חיפוש עם תאריכים ונוסעים,
  מה שהופך scraping אוטומטי לשביר מאוד ולעיתים גם מפר תנאי שימוש.
- ערוצי דילים (כמו secretflights) מפרסמים **מחיר טיסה לנוסע בודד**,
  לא מחיר חבילה כולל ל-5 נוסעים כולל מלון בדירוג מסוים.

**מה שכן עובד ומדויק:** התראה על דילי טיסות אמיתיים מישראל כשהמחיר
לנוסע נמוך מסף שתגדיר (`settings.py -> max_price_usd`, ברירת מחדל $300).
כשמגיעה התראה טובה, אתה בודק ידנית מלון מתאים ליעד ולתאריך.

אם תרצה בעתיד להרחיב את זה לחיפוש חבילות אמיתי, האופציה הריאלית
ביותר היא להתחבר ל-API בתשלום (כמו Kiwi Tequila שכן תומך גם בחבילות,
או Amadeus) - זה שינוי משמעותי יותר, תגיד לי אם תרצה שאבנה את זה.

## שלב 1: יצירת בוט טלגרם

1. פתח שיחה עם [@BotFather](https://t.me/BotFather) בטלגרם
2. שלח `/newbot` ועקוב אחרי ההוראות
3. שמור את ה**טוקן** שתקבל
4. פתח שיחה עם הבוט החדש שלך ושלח לו הודעה (למשל "היי")

## שלב 2: מציאת ה-Chat ID שלך

1. פתח שיחה עם [@userinfobot](https://t.me/userinfobot) בטלגרם
2. שמור את ה-ID שהוא שולח לך

## שלב 3: העלאה ל-GitHub והגדרת Secrets

1. צור ריפוזיטורי (אפשר פרטי) והעלה אליו את כל הקבצים
2. Settings → Secrets and variables → Actions → New repository secret:

| שם | ערך |
|---|---|
| `TELEGRAM_TOKEN` | הטוקן משלב 1 |
| `TELEGRAM_CHAT_ID` | ה-ID משלב 2 |

## שלב 4: הפעלה

- הבוט ירוץ אוטומטית כל 3 שעות (ניתן לשנות ב-`.github/workflows/search.yml`,
  שורת ה-`cron`)
- להרצה ידנית מיידית: טאב **Actions** ברפו → **TisotVeOd** → **Run workflow**

## הרצה מקומית (לבדיקה)

```bash
pip install -r requirements.txt
export TELEGRAM_TOKEN=xxx
export TELEGRAM_CHAT_ID=xxx
python main.py
```

## התאמות

- `settings.py -> SEARCH["max_price_usd"]` - סף מחיר לנוסע (דולר)
- `settings.py -> SEARCH["telegram_channels"]` - רשימת ערוצי טלגרם
  ציבוריים לסריקה (אפשר להוסיף עוד ערוצי דילים ישראליים אם תמצא כאלה)
- `settings.py -> SEARCH["max_results"]` - כמה התראות לשלוח לכל היותר
  בהרצה אחת
- `.github/workflows/search.yml` - שורת ה-`cron` קובעת את התדירות
